# Railway Reservation System

A backend-based Railway Reservation System developed using Java, JDBC, PostgreSQL, and Redis.

## Technologies Used

- Java
- JDBC
- PostgreSQL
- Redis
- Maven
- BCrypt
- Git & GitHub

## Features

- User Registration and Authentication
- Train Search
- Train Management
- Seat Availability Validation
- Ticket Booking
- Ticket Management
- PNR Generation
- Transaction Management
- BCrypt Password Hashing
- Redis Caching for Train Search
